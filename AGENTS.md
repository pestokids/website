## Branches and PRs

- Branch names: `dev/pst-<number>-<short-slug>`, for example `dev/pst-85-name-check`. Always keep the Linear ID; Linear uses it to link the PR.
- If the workspace branch already starts with `dev/` and has the Linear ID, keep it. Rename only if the ID is missing, and only before the first push.
- PR titles in plain English. PR descriptions: no Linear links or internal details (the repo is public).
